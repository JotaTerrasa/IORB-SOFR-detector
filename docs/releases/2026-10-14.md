## Límites

La cartera privada no se publica. Los pesos son referencias estáticas, no posiciones que se revaloricen. No hay ledger completo para calcular el X4, fiscalidad o beneficio total. La API gratuita no aporta todas las métricas de todos los productos: se muestra un guion en vez de cero. La hora de sesión de TradingView no es la del último tick. Históricos TGA/FRED tienen retraso de publicación y siempre indican fecha de observación. Calendarios de catalizadores enlazan a las páginas oficiales.
