Ayuda rápida
Cómo usar (simple)
1) Abre la web → se actualiza sola. 2) Mira Régimen: si dice OPERAR, el Plan te sugiere ABRIR y un Target (si pusiste niveles). 3) Si dice NO OPERAR, espera.
¿Por qué pone NEUTRAL o Confianza BAJA?
- NEUTRAL significa “esperar”: ocurre si estás fuera de paridad, o si el spread no da dirección (cambio 7d ~ 0).
- Confianza (BAJA/MEDIA/ALTA) resume si hay condiciones suficientes (paridad, movimiento del spread, datos/volatilidad) para ejecutar.
Glosario
- SOFR: tasa overnight (NY Fed).
- IORB: tasa sobre reservas (FRED CSV público).
- Spread: SOFR − IORB.
- Paridad: |spread| pequeño (default ±5 bps) → “se puede operar”.
- Rolling corr30: correlación 30d (retornos BTC vs spread).
